# Limitations

The project uses a student survey design and self-reported measures, so the results should be interpreted as associations rather than causal estimates. The public repository excludes respondent-level data, which means canonical results can be reproduced only by someone with approved access to the private questionnaire file.

Model A has limited explanatory power. Model C should be interpreted cautiously because it has a smaller effective sample size and weak explanatory power. The mediation models are exploratory, and `bank_security_control` and the supplementary Q11 trust item are kept separate because they come from different question blocks and serve different analytical roles.
