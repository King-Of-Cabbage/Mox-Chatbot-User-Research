# Limitations

This is a student academic and industry project, not an official statement by HKMA, PolyU, or Mox Bank. The public repository excludes respondent-level data and therefore cannot independently reproduce canonical results without the private questionnaire file.

Model A has limited explanatory power, Model C should be interpreted cautiously, and mediation results are exploratory associations rather than causal evidence. `bank_security_control` and `bank_trust_outcome` are intentionally separated because they come from different question blocks and serve different analytical roles.
