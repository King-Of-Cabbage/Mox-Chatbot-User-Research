# Portfolio Summary

Mox Chatbot User Research is a PolyU × HKMA IPMN academic project about digital banking chatbot user experience. The project examines how users evaluate chatbot service quality, security and control, satisfaction, future use intention, and support for a proposed Mox chatbot service. Mox Bank is used as the project setting, but the analysis and recommendations are student project work rather than official statements by HKMA, PolyU, or Mox Bank.

My main responsibility was the data-processing side of the project. I inspected the raw survey export, applied response-quality rules, cleaned and coded the variables, reverse-coded the Mox-support item, built the composite scores, handled missing values, and prepared the analysis-ready dataset. The public repository keeps the analysis code, aggregate outputs, and synthetic demo runnable while excluding raw respondent records, respondent metadata, open-ended responses, and private questionnaire files.

The final screening process started with 376 responses. After applying the response-time screen and two attention checks, the quality sample contained 232 responses. The main service-quality measure combines five Q10 items covering reliability, ease of use, responsiveness, problem-solving ability, and natural interaction. A separate Q10 measure combines perceived security and perceived control. Satisfaction, trust, and future use intention come from Q11, while support for the proposed Mox chatbot feature comes from Q16 and is reverse-coded so that higher values mean stronger support.

The analysis uses OLS regression with HC3 robust inference as the main reporting standard. Model A tests whether service quality and security/control are associated with satisfaction. Model B tests whether satisfaction, security/control, and service quality are associated with future use intention. Model C tests the same predictors against support for the proposed Mox chatbot context. The mediation models are exploratory and use bootstrap confidence intervals rather than causal language.

The strongest result is in Model B: satisfaction is strongly associated with future use intention, with a coefficient of 0.750 and p<0.001. Model A suggests service quality is associated with satisfaction, but the model explains a limited share of the outcome variance. Model C has low explanatory power and should be read cautiously, especially because the Mox-support item has a smaller effective sample size. The adjusted Mediation B indirect effect is 0.018 with a bootstrap 95% CI of [-0.157, 0.215], so it should be treated as exploratory rather than confirmatory.

The main limitations are the academic survey setting, self-reported measures, limited ability to infer causality, and the need to protect the private questionnaire data. The project is best read as a transparent student research workflow and service-design case study, not as a production decision model.
